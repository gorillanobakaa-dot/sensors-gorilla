# In plain language: everything in this release

<!-- plain-language track: in full, on this page -->

1. **Compiled for every OS — nothing compiles on the fly when you start it.** Linux, macOS, and both Windows editions are now native compiled executables. Startup is instant, with zero Python compilation overhead.
2. **Two Windows editions:**
   - **Windows Generic (`sensors-gorilla`)**: runs out of the box on any Windows 10/11 PC with no drivers required. Reveals NVMe & SATA temperatures and wear/TBW life, battery health and cycle count, live CPU boost frequencies, thermal zone temperatures & throttling, GPU memory and engine load, RAM and commit charge.
   - **ThinkPad L15 Gen 3 (`sensors-gorilla-l15`)**: tailored specifically for the ThinkPad L15 Gen 3 (`21C3CTO1WW`, 12th Gen i7-1255U 2P+8E hybrid CPU, Intel Iris Xe, Micron 1TB NVMe). Separates P-core and E-core clocks and temperatures, reads the ThinkPad Odometer, and (when run elevated with the signed PawnIO driver) reads every core die temperature, RAPL package/core/GPU wattage, PCH chipset temperature, and ThinkPad EC fan RPM safely read-only. Built with zero TPFanControl code.
3. **Full 24-bit TrueColor on Windows Terminal.** Smooth 16.7M-color thermal gradients, gradient progress bars, gradient separator rules, and the cyan-orange-red Gorilla Skynet System banner, with instant reflow when you resize or maximise Windows Terminal.
4. **All operating systems on one page.** Windows Generic, Windows ThinkPad L15 Gen 3, Linux, and macOS are all built, tested, checksummed, and published together here.

# For developers: how it works, and how to check it

<!-- developer track: in full, on this page -->

- **Zero external crates.** Built from Rust `std` only (`[dependencies]` is empty) with `--offline --locked`, `opt-level = 3`, `lto = true`, `strip = true`, and static CRT (`+crt-static` on Windows, `x86_64-unknown-linux-musl` on Linux, universal `x86_64`+`arm64` Mach-O on macOS).
- **Windows hardware access:** `DeviceIoControl` (`IOCTL_STORAGE_QUERY_PROPERTY` NVMe Log Page `0x02`, `IOCTL_BATTERY_QUERY_*`), `CallNtPowerInformation`, `GetLogicalProcessorInformationEx` (hybrid `EfficiencyClass`), `PDH` counters, COM `IWbemLocator` WMI (no PowerShell subprocesses), `nvml.dll` dynamic probe, HWiNFO/LHM optional bridges, and optional SHA-256-verified read-only `PawnIOLib.dll` (`IntelMSR.bin`, `IntelPCHThermal.bin`, `AMDFamily17.bin`, `LpcThinkpadEC.bin`).
- **PawnIO fail-closed check:** Every `.bin` module is checked against its pinned SHA-256 digest before calling `pawnio_load`. EC reads use only ACPI EC command `0x80` (read) on the `0x1600`/`0x1604` sideband window under `Global\Access_EC`.
